They remain unverified. On the same date the user removed the requirement that PAL prevent writes independently of saved agy settings. False omits PAL's mode override; true requests `--mode accept-edits`. Neither path changes saved configuration or authentication. The former permission blocker is removed. Do not substitute a prompt instruction for enforcement, invent a default-mode flag, force an API key, or automatically modify user settings.

## Repository orientation

`ClinkRegistry` loads built-in JSON manifests, then environment and user overrides. Names still need an entry in `INTERNAL_DEFAULTS`; manifest-only registration is insufficient. `CLinkTool` builds its CLI/role schema from this registry. New multi-client requests require `cli_name`; continuations inherit successful selection and sole-client requests select that client. The cached metadata default separately prefers Gemini. Tests must construct a new registry/tool after changing fixture configuration rather than relying on stale singletons.

`CLinkTool.execute()` owns coordination and delegates to `_execute_coordinated()` for both MCP and direct calls. `clink/conversation.py::prepare_request()` expands a user-supplied `prompt.txt`; `CLIConversation.load()` prepares a snapshot without storing the current turn. Client-specific edit-scope validation precedes role-prompt loading and agent creation. `prepare_history()` uses `render_history()` and passes bounded `user_content` to `_prepare_prompt_for_role()`. `CLIConversation.commit()` records both raw turns together after success. `server._dispatch_tool()` uses this public path without reconstructing a separate prompt. Preserve it; do not reintroduce the obsolete decorator, add a history store, or use native agy continuation.

`BaseCLIAgent.run()` owns the working-directory and progress contexts; `_run_in_directory()` constructs the process and currently passes UTF-8 prompt bytes to `communicate()`. `_build_environment()` filters inherited variables, so agy needs the design's explicit authentication passthrough. An absent configured `working_dir` produces a fresh scratch cwd; project files remain absolute references outside it. Its command hooks do not receive the assembled user prompt. Parsers return `ParsedCLIResponse`; `ParserError` is wrapped as `CLIAgentError`. The tool turns agent errors into `ToolExecutionError` responses. Reuse the existing `ExitStack` output-file cleanup and `_kill_and_reap()` cancellation/timeout handling.

Read these anchors before implementation:

- `clink/parsers/base.py`, `clink/parsers/codex.py`, `clink/parsers/__init__.py`.

- `tests/test_clink_claude_agent.py`, `tests/test_clink_gemini_agent.py`, `tests/test_clink_safe_default.py`, and `tests/test_clink_tool.py` for subprocess fakes and existing contracts.
- `tests/test_clink_environment.py`, `tests/test_clink_continuation.py`, `tests/test_clink_concurrency.py`, and `tests/test_clink_history_budget.py` for environment/cwd/cleanup contracts, history, and MCP/direct invocation parity.
- `simulator_tests/base_test.py`, `simulator_tests/test_basic_conversation.py`, and `simulator_tests/__init__.py` for simulator registration.

Do not copy permissive parser fallbacks or integration tests that convert CLI errors into skips. New acceptance checks must fail when a configured agy invocation fails. Use the existing Python environment and dependency set; no dependency additions are planned.

Missing account coverage must still be completed before release; never relabel an unrun case as passing because the permission contract changed.

### Verified invocation contract

**Observed invocation and approved mapping, 2026-10-14.** `agy --input-format stream-json --output-format stream-json` completed one message plus EOF through `BaseCLIAgent` in both cwd modes using the existing enterprise login with no forwarded API key. Configured-project reads succeeded; scratch-mode external reads passed after the operator enabled `allowNonWorkspaceAccess`. Adding `--mode accept-edits` performed the intended fixture edits in both modes with unchanged settings in stable repeats. See [capability-evidence.md](./capability-evidence.md).

Map false to the protocol-only invocation and true to the same command plus exactly one `--mode accept-edits`. Keep built-in `safe_args`/`edit_args` empty for agy; let the adapter own mode insertion and reject configured mode/bypass overrides. False inherits saved agy permissions and is not a read-only guarantee. True requests native edit approval and leaves other permission rules to agy. The reported `--mode default` rejection is tracked by [upstream #1233](https://github.com/google-antigravity/antigravity-cli/issues/1233); no unverified downgrade flag is part of this contract. The authentication follow-up verified synthetic forwarding, an explicit missing-ADC failure, and continued enterprise-login success; unavailable authentication cases now belong to Task 6 by user approval.
